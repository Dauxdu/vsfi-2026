### 🟢 HUB (Базовая инфраструктура и запуск сервисов)

**1. Street terminal online (hub-01)**

- **Сложность / Награда:** LOW / 15 eddies
- **Описание:** Сделать форк репозитория `https://git.vsfi.ru/vsfi-2026/night-city-net`. Запустить фронтенд на `app-vm` [VM на вашем ноутбуке].
- **Критерии сдачи:** Репозиторий в GitLab команды [fork], приложение доступно по HTTP с `app-vm` [IP/порт].

**2. Domain bridge (hub-02)**

- **Сложность / Награда:** MEDIUM / 20 eddies
- **Описание:** На VM организаторов привязан домен `teamN.vsfi.team`. Разверните веб-сервер и проксируйте на фронт с `app-vm`. Приложение должно отвечать по домену. TLS - самоподписанный сертификат.
- **Критерии сдачи:** `https://teamN.vsfi.team` открывает Night City [прокси на ваш фронт]. Самоподписанный сертификат на домене (в CN сертификата надо домен прописать, а не Traefik Default Cert).

**3. Job generator live (hub-03)**

- **Сложность / Награда:** MEDIUM / 25 eddies
- **Описание:** Сделать форк репозитория `https://git.vsfi.ru/vsfi-2026/night-city-job-generator`. Бэкенд на `app-vm`, PostgreSQL на `db-vm`. По домену в UI виден список jobs.
- **Критерии сдачи:** Postgres на `db-vm`, бэкенд коннектится к нему. API `/jobs` отвечает; на `teamN.vsfi.team` в борде видны jobs, система не OFFLINE.

**4. Risk oracle wired (hub-04)**

- **Сложность / Награда:** MEDIUM / 25 eddies
- **Описание:** Сделать форк репозитория `https://git.vsfi.ru/vsfi-2026/ml-risk`. Запустите на `app-vm` и подключите к бэкенду. В борде у заказов отображается уровень риска.
- **Критерии сдачи:** `ml-risk` отвечает на `/health` и `/predict`, бэкенд ходит в ML; в UI виден risk (не вечный Unknown при живом ML).

### 🟠 Ansible (Автоматизация развертывания)

**8. Ansible·frontend roll (ansible-01)**

- **Сложность / Награда:** MEDIUM / 20 eddies
- **Описание:** Ansible-роль обновляет фронт на `app-vm`. Все роли команды храните в отдельном GitLab-репозитории.
- **Критерии сдачи:** Роль в отдельном ansible-репозитории команды. Повторный прогон идемпотентен. После прогона фронт на `app-vm` актуален.

**9. Ansible·backend roll (ansible-02)**

- **Сложность / Награда:** MEDIUM / 20 eddies
- **Описание:** Ansible-роль обновляет бэкенд на `app-vm` [и при необходимости доступ к `db-vm`]. Роль в общем ansible-репозитории команды.
- **Критерии сдачи:** Роль в ansible-репозитории команды. Идемпотентный прогон. Jobs API жив после деплоя.

**10. Ansible·ml-risk roll (ansible-03)**

- **Сложность / Награда:** MEDIUM / 20 eddies
- **Описание:** Ansible-роль обновляет `ml-risk` на `app-vm`. Роль в общем ansible-репозитории команды.
- **Критерии сдачи:** Роль в ansible-репозитории команды. Идемпотентный прогон. `/predict` отвечает после деплоя.

**11. Ansible·postgres roll (ansible-04)**

- **Сложность / Награда:** MEDIUM / 20 eddies
- **Описание:** Ansible-роль разворачивает PostgreSQL на `db-vm`. Роль в общем ansible-репозитории команды.
- **Критерии сдачи:** Роль в ansible-репозитории команды. Идемпотентный прогон. Поднимает/настраивает Postgres на `db-vm`. Бэкенд успешно коннектится к БД после прогона.

### 🟡 Monitor (Мониторинг и алертинг)

**16. Eyes of NetWatch (mon-01)**

- **Сложность / Награда:** MEDIUM / 25 eddies
- **Описание:** Разверните Grafana + Prometheus. Grafana на `gr.teamN.vsfi.team` [самоподписанный TLS].
- **Критерии сдачи:** Prometheus собирает хотя бы базовые targets. Grafana доступна на `https://gr.teamN.vsfi.team`. Datasource Prometheus настроен.

**17. Fleet dashboard (mon-02)**

- **Сложность / Награда:** MEDIUM / 20 eddies
- **Описание:** Дашборд в Grafana по всем VM [CPU/RAM/disk/network - разумный минимум].
- **Критерии сдачи:** Дашборд в Grafana на `gr.teamN.vsfi.team`. Видны все заявленные VM.

**18. Node pulse (mon-03)**

- **Сложность / Награда:** LOW / 15 eddies
- **Описание:** Ansible-роль ставит `node_exporter` на все ваши машины [`app-vm`, `db-vm`, ...]. Роль в ansible-репозитории команды.
- **Критерии сдачи:** Роль в ansible-репозитории команды. `node_exporter` на всех заявленных VM. Targets UP в Prometheus.

**19. Alarm wired (mon-04)**

- **Сложность / Награда:** MEDIUM / 20 eddies
- **Описание:** Алерт на метрику [instance down / disk / HTTP probe - на выбор, но осмысленный].
- **Критерии сдачи:** Alert rule в Prometheus/Alertmanager [или Grafana alerting]. Жюри видит правило и демо срабатывания / firing history.

**20. Backend telemetry boards (mon-05)**

- **Сложность / Награда:** HIGH / 25 eddies
- **Описание:** Сбор метрик бэкенда. Два дашборда: бизнес-метрики jobs и отдельно Go-метрики.
- **Критерии сдачи:** `teamN.vsfi.team/metrics` бэка скрейпится Prometheus. Dashboard business [jobs / accept / generate и т.п.]. Dashboard Go/process.

**21. Nginx under glass (mon-06)**

- **Сложность / Награда:** MEDIUM / 20 eddies
- **Описание:** Сбор метрик Nginx и дашборда в Grafana.
- **Критерии сдачи:** Exporter/метрики nginx в Prometheus. Дашборд [RPS/connections/ошибки - минимум].

**22. Backend logstream (mon-07)**

- **Сложность / Награда:** HIGH / 25 eddies
- **Описание:** Сбор логов бэкенда и визуализация в Grafana [Loki / Elasticsearch / иной стек - на выбор].
- **Критерии сдачи:** Логи бэка попадают в систему сбора. В Grafana можно найти свежие логи [explore/dashboard].
